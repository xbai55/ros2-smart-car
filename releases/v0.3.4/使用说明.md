# InsightRover 智巡 · Windows 试用版 0.3.4

适用于 Windows 10 / 11 的 64 位电脑。安装包自带运行环境，不需要另装 Python、Node.js、ROS 或手动运行启动脚本。小车需要提前部署兼容的车端服务。

## 安装与首次连接

1. 运行 `InsightRover-Setup-0.3.4-x64.exe`，按向导完成安装。默认只安装到当前 Windows 用户，不需要管理员权限。
2. 从开始菜单打开“InsightRover 智巡”。首次启动时创建管理员账户，密码至少 8 位。安装包不带固定的默认管理员密码。
3. 填写小车当前 IP、网页端口（通常为 `8080`），以及 SSH 用户名（通常为 `jetson`）、SSH 登录密码和端口（通常为 `22`）。SSH 密码与网页账户密码是两回事，不会保存到本机配置或安装包。
4. 在“本次需要更换小车 Wi-Fi 吗？”中选择：
   - **不需要**：点击“连接并启动小车”。应用通过 SSH 停止厂家程序并启动已部署的智巡服务，确认状态接口就绪后打开登录页。已有智巡服务运行时直接复用，不打断现有任务。
   - **需要**：填写目标 Wi-Fi 名称和密码，可勾选隐藏网络；点击“更换 Wi-Fi 并连接”。提交后请让电脑连接目标网络，并在提示窗口填写换网后的小车 IP（可在路由器设备列表或小车本机查看）。应用重新连接并核对真实 Wi-Fi，再启动服务；仅提交指令不会被当作连接成功。此版支持带密码的 WPA/WPA2-PSK 网络，不适用于网页认证或企业认证网络。
5. 首次使用时创建此电脑上的网页管理员账户，然后在浏览器登录。首次安装是空白业务数据库，不包含其他电脑的任务或地图。

第一次 SSH 连接会显示小车主机指纹，确认后保存在数据目录的 `known_hosts`。换网前后会核对同一台小车身份，已知指纹不匹配时停止连接。Wi-Fi 切换失败时会尝试恢复原网络；如果新 IP 填错或主动取消，不会宣称换网成功，可确认地址后选择“不需要”重试。

应用只在用户点击连接时启动小车程序，不会永久修改厂家自启动或启用车端开机自启。应用默认让新启动的智巡服务处于停车模式，不发送移动指令；小车需已部署约定的智巡服务，SSH 账户需有用户级 systemd，换网另需 sudo 与 NetworkManager。启动脚本目前针对本项目 `/home/jetson/ros2-smart-car-mapping-settings-20261020/start_test.sh` 部署。

关闭应用会停止它管理的本机后台，小车端服务继续运行。离线查看地图可以点击“离线打开控制台”；实时功能需要连接小车。重复打开应用不会再启动第二套本机后台。

本安装包尚未进行代码签名，Windows 可能显示“未知发布者”。请确认文件来自可信的交付来源后再安装，不需要关闭杀毒软件。

## 地图与配置存在哪里

默认数据目录：`%LOCALAPPDATA%\InsightRover`。在文件资源管理器地址栏输入该路径即可打开，也可以点击应用窗口中的“打开数据目录”。

- `smart_patrol.db`：账户、任务、地图登记等业务数据。
- `storage`：地图及其他媒体文件。仅备份数据库不足以保留完整地图。
- `config.json`：小车 IP、网页/SSH 端口、SSH 用户名和本机网页登录密钥。不要公开分享此文件。
- `backups`：新版本进行数据库结构迁移前的数据库与配置备份。
- `logs`：应用后台运行日志。

程序默认安装在 `%LOCALAPPDATA%\Programs\InsightRover`，与上述数据目录分开。以后运行新版本安装包即可更新程序，已有数据不随程序替换；卸载程序也会保留数据目录。备份完整数据时，请先关闭应用，再复制整个数据目录。

每台电脑使用自己的数据库，连接同一台小车不会自动共享任务或地图记录。完整建图输入日志仍记录在小车端，不会因电脑应用升级而转移或删除。

安装包不含当前开发项目的数据库、地图、SSH 密码或个人登录凭据。已有开发版数据不会自动迁入这一版应用，需要另行迁移。

## 源码与再次构建

桌面入口位于 `desktop/desktop_entry.py`，启动管理、独立数据目录和本地代理在 `desktop/insightrover_desktop/`。网页和业务后端复用现有项目。构建脚本为 `desktop/build_windows.py`，安装脚本为 `desktop/installer.iss`。

构建需要 Python、Node.js、PyInstaller 和 Inno Setup；这些是开发工具，使用安装包的人不需要安装。安装器使用 [Inno Setup](https://jrsoftware.org/isinfo.php)，相关工具和运行库遵循各自许可，见 `THIRD_PARTY_NOTICES.txt`。

## 0.3.3 地图显示与对齐改进

导航页的小车、目标和标定点使用固定屏幕尺寸；保存的 SLAM 栅格图放大时保持清晰的像素边界。地图空间不足时，目的地操作移至下方。保存地图与实时地图的标签区分，格数和每格尺寸明确显示。放大不会增加原始地图的采样精度。

四点对齐增加拟合残差预览、点位集中提示和单组重选。10 cm 保存门槛仍由车端执行，未放宽阈值；残差小也不代表实车定位正确。建议使用房间四周的实体墙角，避免仅在窄走廊两端选点；局部不按比例的示意图和已变形的 SLAM 图需要先修正。

## SLAM 直接导航（0.3.3）

默认使用“SLAM 直接导航”：在当前 SLAM 地图的已知空地上选点，预览路线，再启动导航。不需要上传平面图或人工选四个对应点；系统通过地图分辨率、原点和坐标系自动核对坐标，并保留车端原有安全检查。

要长期保存地点，先保存当前 SLAM 地图，或在下拉框选择已保存的 SLAM 地图；历史地图需加载到小车并完成初始定位，地图坐标核对后可保存地点，定位和导航服务就绪后才可行驶。地点绑定对应地图，并与地图管理页共用记录。切换地图或建图会话后，旧目标和预览路线失效。

“平面图融合 · 进阶”保留上传图纸、四点对齐和融合显示。基础 SLAM 导航不依赖此功能。临时地图可以选目标，但长期地点需先保存地图。没有修改小车的安全门槛，也没有自动开始运动。

## 0.3.4 更新

程序文件、安装器、开始菜单和桌面快捷方式、启动窗口统一使用蓝色小车图标。直接运行新版安装包覆盖升级，已有账户、地图和配置仍保存在独立数据目录。

本轮车端修复：导航启动参数兼容 Humble；退出建图后停止 SLAM 并保留最后栅格；停车定位增加至少 3 秒稳定性检查，位置变化范围不超过 5 cm、朝向范围不超过 3°，同时保留原协方差门槛。这些是启动与就绪检查，不代表实际行驶精度验收。

上述修复已部署到本次连接的小车。Windows 安装包不会更新其他小车的 ROS 程序；随交付提供的车端修复源码需按目标小车工作空间单独部署。重新加载历史地图后仍须设置实际位置和车头朝向。
