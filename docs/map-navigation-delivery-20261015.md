# 地图优化、地图对齐与文件运输

2026-10-15。本轮完成本地实现、模拟接口回归和浏览器流程检查。用户确认小车暂不在线，因此未部署车端、未启动真实 Nav2，也未让小车移动。这里的模拟截图不属于实车验收证据。

## 地图清晰度与优化

检查的四份车端原始地图与导入后的栅格逐像素一致，原版 gmapping 和当前 slam_toolbox 配置都是 0.05 米/格。本地证据未显示保存时发生缩采样；这不能排除实际移动建图出现重影、漂移或覆盖不足。

地图管理的 SLAM 预览改为按栅格显示，避免小图放大时插值发糊。新保存文件将 25–64 的不确定占据值保留为未知区；PGM 中未知灰度 205 配合 YAML 的 free_thresh=0.196，重新加载时不会被误读成空地。原始快照继续保留。历史资产文件不被批量覆盖；通过新版加载入口使用历史快照时，会重新生成匹配阈值的导航文件。

在“地图管理 → SLAM 地图详情 → 预览与编辑”中，可以清理 1–8 格的孤立占据连通区域、点击两个端点补墙、调整墙宽和撤销操作。清噪把孤立点改为未知区，不自动制造通道；补墙只增加障碍。检查预览中的门口与通道后，保存为独立版本。父图、比例和原点保留，版本记录保存父图标识、编辑操作与内容摘要。

自动拉直整面墙没有纳入本轮。墙体弯曲如果来自定位漂移，后处理不能恢复真实几何，需要上线后用同场景、同轨迹比较原始建图。

## 两张地图如何联通

导航工作区保留参考平面图和真实 SLAM 栅格。选用地图仍只改变界面配置；“加载并启动定位”才会把保存的 SLAM 快照安装到车端、结束 SLAM 建图进程并启动地图服务、AMCL 和 Nav2。该操作要求停止模式、有效里程计，并同时核对纵向与横向速度。

加载后，在 SLAM 画布点选小车实际位置并填写初始朝向。朝向使用 map 坐标系，0° 沿 X 正方向，90° 沿 Y 正方向。系统要求初始位置之后的连续有效 AMCL 观测、协方差阈值与新鲜状态；仅发送位置不会被视为定位完成。定位观测超时会阻止导航。协方差检查不能代替现场核对雷达和墙体重合。

选择上传的参考平面图，用四组分散的固定位置完成对齐。目标位置和朝向一起变换到小车坐标。地图身份包含建图会话或已验证资产摘要；换图、重建图、图纸版本改变后，旧标定和旧路线不能静默复用。业务网关还须与当前前端控制会话一致，避免两个服务误连不同小车。

上传图中的墙线只作参考，不自动成为导航障碍。真正的通行判断使用 SLAM 栅格和实时传感器。目标若落在障碍、未知区或安全边界内，车端会拒绝。

## 文件运输与巡航

在“机器人运行 → 地图与导航”选择目的地及到达朝向，地图下方可新建执行任务，或关联尚未派发的业务任务。关联机器人使用业务数据库中的记录。

运输流程为：创建任务 → 等待人工放入文件 → 点击“已装件，开始运输” → 收到对应 Nav2 目标成功结果 → 等待人工取件 → 确认取件 → 完成。勾选返程时，取件确认后重新规划回到创建任务时的小车位置，到达后才完成任务。

巡航可以按顺序添加 1–30 个站点，每段都从当前位姿重新规划，并逐段核对目标结果；可选完成后返程。暂停会取消当前目标，恢复时重新规划未完成路段。停止、取消、急停和切离导航模式都会中断任务。车端进程重启后，未完成任务进入失败状态，不自动恢复运动。

任务中心可查看执行记录并操作装件、暂停、恢复、取件和取消。状态只依据匹配的 run_id、goal_id 和递增版本更新。迟到的轮询不能撤销取消结果；重复读取不会改变完成时间。已绑定执行的任务拒绝通过旧业务接口手工改成完成。未确认派发可以重试原请求；取消会在车端留下记录，阻止迟到请求重新创建任务。

## 小车上线后的验收

1. 配套更新车端 ROS 包、状态节点、前端和业务后端；车端需要 ROS 2 Humble、Nav2、slam_toolbox、std_srvs。Windows 本地检查不能证明 ROS 启动成功。保留车端当前部署和地图文件以便回退。
2. 确认前端与业务网关连接同一台车。小车停稳，核对里程计二维速度、控制输出与急停状态，加载覆盖运输区域的 SLAM 地图。
3. 设置真实初始位置和朝向，核对只有一个 map→odom 发布源、AMCL 正常、雷达与地图重合。四点标定后，再用未参加拟合的实际位置检查误差。
4. 现场有人值守且可立即急停时，先以低速完成邻近空地到点，再测 A→B 运输、取件确认和返回起点。记录实际停车位置与朝向，不把页面完成当作验收通过。
5. 分别检查临时障碍、规划中停止、途中暂停恢复、急停、定位失效和服务重启。记录车轮是否确实停止及业务状态是否一致。

目前尚未验证真实地图加载、AMCL 收敛、实际 A* 路径、DWB 避障、停车误差与运输成功率。车体包络、通道宽度和防撞阈值需要现场核对。
