# 地图编辑与导航优化

入口：地图管理 → SLAM 地图详情 → 地图优化 → 预览与编辑。

已有地图、原始栅格和旧版本保留。所有编辑均另存为新地图；选用地图只是业务配置，保存编辑不会加载到小车。

## 编辑

- 选择地形栅格或禁行遮罩，再选择画笔、直线、矩形。地形可设为障碍、可通行或未知；禁行遮罩仅添加或擦除。矩形可填充。
- 自动分析 8 邻域小孤立障碍，默认上限 2 格，可调 1、2、3、4、6、8 格。候选先选中供检查，但没有立即修改。支持逐项、全选和手工绘制；默认改为未知，明确确认后才清为可通行。候选不是对椅子的语义识别。
- 平移、滚轮与双指缩放、适应窗口、网格、测距、反色和增强对比均为编辑辅助。反色和对比不改变真实占用状态。
- Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做；关闭和离开页面会提示未保存的修改。每版本最多 100 步，超出时先保存再继续编辑。
- 原图与修改预览保持相同视窗，青色表示修改区域。候选列表显示前 200 项，地图按视窗最多显示 800 个候选；全选处理完整结果。候选超过 20000 项时要求先人工分区清理。

红色是原始禁行遮罩，浅红色是按半径扩大后的方形保守包络，包含原始禁行范围。预览默认半径 0.25 米，可调整；车端始终按自己的实际配置重新生成包络。修改底图不会擦除禁行区。保留门口开口，不将未探测空间自动变成通路。

## 导入导出与版本

地图列表的“导入 ROS 地图”接受 P2/P5 PGM 与 trinary YAML，可附独立禁行 PGM/YAML。每个 PGM 上限 40 MB、每个 YAML 上限 64 KB、地图上限 1600 万格；YAML image 必须是同次上传 PGM 的文件名，不读取服务器本机路径或网络文件。尺寸、分辨率、原点须与遮罩严格一致。

地图详情可导出 ZIP，含 map.pgm、map.yaml、preview.png、snapshot.json、version.json；存在遮罩时另含 keepout.pgm、keepout.yaml 和 keepout.png。地图几何信息不因编辑而改变，保留父版本、操作与底图/遮罩摘要。

已有预览、另存接口扩展编辑类型并兼容旧清噪和补墙。新增接口：

- POST `/api/v1/maps/{id}/cleanup-candidates`：请求当前编辑操作，查询 `max_cells`，返回候选。
- POST `/api/v1/maps/import-ros`：JSON 上传地图对和可选遮罩对；PGM 为 base64，YAML 为文本。
- GET `/api/v1/maps/{id}/export-ros`：下载完整 ZIP。
- 预览增加修改高亮、禁行区、扩展边界图及面积；`radius_m` 仅控制显示。

地图管理权限才能导入、编辑与分析，已有地图读取权限可导出。

## 导航与回退

小车静止并取消现有导航/巡航后，手动“加载并启动定位”，再重新设置初始位置与校准。加载新版本会使旧校准和规划失效；回退使用同一流程加载原图。

定位仍使用真实地形，不把禁行区域写进 AMCL 地图。遮罩单独进入 Nav2 Humble 的全局和局部 Keepout Filter，服务端先检查车端 `keepout-v1` 能力；车端联合校验版本、栅格与遮罩，确认遮罩和 FilterInfo 均匹配后才允许导航。

全局地图配置静态层、二维 `/scan` 障碍层和膨胀层；局部地图为 4×4 米滚动窗口、二维雷达障碍层与膨胀层，不继续依赖旧静态杂物。默认障碍标记 3 米、射线清除 3.5 米，保持无穷距离无效；地图格不会仅因观测缓存超时自动视为空闲。全局重规划沿用 Nav2 的重规划行为树。急停、雷达故障停车与唯一速度输出不变。

必须配套更新业务后端、前端和车端。只更新网页不能让车端执行新遮罩。上线前核对 ROS Humble、Nav2 插件、实测车体半径及雷达范围，再开展静止检查与有人看护的低速测试。

## 验证边界

本次进行本地测试与隔离浏览器操作验证，未连接小车，未完成 ROS 运行级仿真/录包或实车避障验收。配置和纯软件测试不能证明椅子腿一定被现场雷达检测到。

1600 万格地图已进行独立性能检查，结果保存在 `output/map-editor-20261019/performance.json`；大图预览需要等待，不保证即时反馈。浏览器测试图、账号和新版本仅在独立测试数据库中，未写入正式业务数据。
