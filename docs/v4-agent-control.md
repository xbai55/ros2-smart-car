# v4 Agent 任务控制接口（4.0.1）

用户明确要求执行任务时，模型调用 execute_plan，经服务端权限、真实状态、资源和能力验收核验后，由持久执行器调用业务控制入口。用户只要求计划时继续使用 propose_plan 保存草案并等待页面确认。新增系统诊断、视觉设置和恢复工具见 [Agent 系统工具](agent-system-tools.md)。不能从模型自由文本中抽取 Shell、任意 HTTP、ROS 话题或速度直接执行。

## 新增受限前进

结构为 {"action":"move_relative","distance_m":0.20}，仅向前 5—20 厘米，首版只允许单步计划。距离缺失、超限、后退或旋转应澄清，不能自行替换用户目标。

执行器使用真实 odom 的位置与初始朝向计算前向距离，不依赖地图，也不把 odom 当作地图坐标。速度指令上限固定 0.10 米/秒，最长 4.5 秒；达到距离、传感器陈旧、时间回退、方向偏离、失去控制权、取消或异常时结束并停车。实际未到达不得写为完成。

车端租约新增 forward_limit_mps，由执行器签发，控制器回执必须确认同一限制。控制器在最终输出前限制前向速度，并拒绝该租约下的后退、侧移或转向输出；避障产生绕行意图时保持停止。续约不能移除限幅。旧车端缺少 bounded_forward_supported 时不开放入口。

任务通过现有机器鉴权、单车执行租约、驾驶序号和独立停车接口执行。连接在短距循环内复用。主机重启、派发结果不明或执行中断后不自动重放位移，需结束旧执行并重新生成草案。

## 管理员单次现场授权

POST /api/v1/assistant/plans/{id}/trial-authorize 提交当前 version 和 digest。要求计划归属，以及 assistant.settings、assistant.use、robots.manage、robots.control 权限。

仅支持单步 move_relative 或 observe_target。必须得到当前支持、就绪状态；授权绑定计划、用户、版本、摘要和能力指纹，最长五分钟。确认时原子绑定唯一执行 ID，其他执行不能复用。确认后重复请求返回同一执行。

授权不写入 CapabilityAcceptance，不将 accepted 改为 true，也不能放开导航、巡检、运输或路线搜索。每次派发仍核对授权；过期或权限变化后结束任务。普通账号不获得测试入口。

桌宠任务卡展示距离、限速、时限及能力拒绝原因。管理员可选择“确认并执行一次现场测试”。模型没有单次现场测试授权工具，直接执行也不能绕过验收或代办人工交接。

POST /api/v1/assistant/plans/{id}/refresh 在原执行已经结束时重新核验相同任务意图，保存新的待确认草案和审计，不重新调用模型、不复制现场授权，也不直接执行。

## v4.0.0 历史交付边界

真实 DeepSeek 已通过正式 Agent HTTP 接口生成“前进20厘米”和“静止识别瓶子”的正确草案。首次前进确实经授权和执行器下发，但约前进2.3厘米后到达时限、确认停车，未达到目标。后续代码已优化连接复用；完整端到端成功尚未证实。

随后车端磁盘写满，诊断日志写入异常导致 Web 节点退出，复测未再次发车。诊断日志代码已增加限额轮转和写入异常隔离；这不代表已经解决车端磁盘占用。

按用户要求，现已停止模型及实车验证，车端测试服务保持停止。最后收尾的控制器限幅、日志保护和界面重试尚未进行新的功能回归。交付包是代码构建产物，不标记为实车验收通过。
