# 上传平面图与 SLAM 的标定和可视化

更新：2026-10-13。以下功能已配套部署到小车新版目录。本文的融合截图和路线测试使用模拟节点；后续真实静止验证已完成视频、传感器、SLAM初始化、文件保存，以及上传图进入标定界面。实际对应点标定和实车导航尚未验收，结果见工作区 `output/deployment-20261013/部署与静止验证记录.md`。

## 开源项目的参考方式

| 项目 | 已核实的实现思路 | 本项目采用的做法 |
| --- | --- | --- |
| [ROS 2 Web2D](https://github.com/Neoplanetz/ros2-web2d) | 在同一场景显示占据栅格、路径、位姿、标记和扫描；通过 TF 转换到统一坐标系；地图颜色与叠加透明度可配置 | 以真实栅格为主画布，将平面图、地点和路线投影到相同地图坐标 |
| [Open-RMF Web](https://github.com/open-rmf/rmf-web) 与 [Traffic Editor](https://github.com/open-rmf/rmf_traffic_editor) | 业务控制台与地图组合；图纸通过参照点、尺度、旋转和平移注册到场地坐标 | 上传图片保留像素坐标，通过人工对应点注册到小车的米制坐标 |
| [Vizanti ROS 2 分支](https://github.com/MoffKalast/vizanti/tree/ros2) | 浏览器中的 RViz 风格二维可视化，支持手机操作、目标和任务规划 | 减少来回切换地图，提供拖动、缩放、跟随、图层开关和清楚的状态 |

Open-RMF 的坐标转换可直接查看 [transform.py](https://github.com/open-rmf/rmf_traffic_editor/blob/main/rmf_building_map_tools/building_map/transform.py)。这些项目的实现并不要求把两张图片永久合成一张。本项目参考了场景分层和图纸注册的思路，没有引入这些项目的新运行依赖或复制其源码。

## 现在怎么操作

1. 在“地图管理”上传 PNG/JPG/WebP，可先标注地点。
2. 在智巡一号“实操”的“地图与导航”区域，选择“参考平面图”。需登录业务账户才能读取已上传图片；停用的图片不出现在选择列表中。
3. 先取得真实 SLAM 地图，再点“地图对齐”。依次在左侧图片和右侧 SLAM 地图中选择四个相同位置，尽量选分散的固定墙角或物体端点。可撤销上一步。
4. 点“保存对齐”。后端拒绝重复、集中或共线的选点，也拒绝最大拟合误差超过 0.10 m 的结果。
5. 返回“SLAM 融合视图”：平面图作为可开关的参考层，小车、地点、目标和路线显示在相同坐标系。可调透明度、切换浅色/深色、跟随小车、适配和导出 PNG。
6. 点击地点或地图位置，先“预览路线”，再“开始导航”。后者仍需真实 Nav2、定位、雷达等服务就绪，标定完成不会自动启动 Nav2。

四点误差表示选点拟合情况，不能用作整张图的定位精度承诺。任意手绘图、透视照片或比例失真的图，可能无法通过一个仿射变换准确对齐整个场地。应使用比例可靠的平面图。

## 坐标与数据边界

上传图使用左上角为原点的图片像素；机器人使用 ROS `map` 坐标，单位为米。四组点拟合六个仿射参数：

```
X = a*u + b*v + c
Y = d*u + e*v + f
```

图层渲染还考虑栅格原点、原点旋转、分辨率以及画布上下方向。图片自身不会被转换成障碍栅格。实测障碍始终绘制在参考图之上，界面美化不删除障碍或补造墙体。

内置实验室示意图仍沿用既有墙和实验台障碍叠加。用户上传图使用测得的占据数据，不套用内置实验室的障碍轮廓。上传图中画出的墙不自动成为避障约束；如果雷达无法检测某类障碍，必须另行建模，不能以图片画面代替检测。

标定记录包含图片 ID、尺寸、类型和稳定图片版本标识，保存于车端导航配置。图片重命名不使标定失效，切换图片则重新检查身份并清除跨图的导航预设。业务数据库中的上传图片与标注地点保留，导航保存的预设与业务标注仍是两套存储。

当前只保留一份活动标定，尚未建立每张图片的标定历史库。切换并重新标定另一张图后，原图需要重新标定。地图元数据变化、选图变化或标定变化会使旧路线预览失效；保存导航地点也核对当前地图、矩阵和图片身份，防止多客户端错用坐标。

点击“开始建图／重新建图”会使当前标定失效，即使新栅格尺寸和原点碰巧相同，也不能沿用旧坐标。图片身份和预设像素点保留；重新标定成功后才能用于导航。页面每三秒同步导航配置，以反映其他客户端的标定修改。

“导出地图视图 PNG”是展示截图，与“SLAM 建图→保存地图”的 YAML/PGM 导航文件不同。
