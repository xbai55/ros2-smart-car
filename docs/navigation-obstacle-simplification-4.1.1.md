# 4.1.1 导航避障简化

代码修改阶段仅进行了本地代码修改与离线验证；后续经授权部署和实测的结果见文末。保留此前导航交接和预览网关修复及其他工作区内容。

## 对比依据

本地 main=39508a1。main 和当前版本均使用 DWB、NavFn、雷达 obstacle_layer、速度平滑器，main 本身也有自研预测几何检查，并不能仅凭分支名称证明当前硬件已经验收。当前版本使用操作者提供的实测矩形 [[0.0935,0.1],[0.0935,-0.1],[-0.1565,-0.1],[-0.1565,0.1]]；保持尺寸，不回退到 main 的 0.25 米圆形近似。

4.1.1 local_guard 在未来轨迹检查之外又按请求角速度扩张整条轨迹，且一次 braking 就撤销导航租约。本轮导航使用同一套矩形轨迹检查，去掉重复的未来角速度扩张，只补偿扫描以来实测旋转，仍保留实测速度、观测年龄和制动模型。手动链路原防护算法不变。

## 开关与行为

首次默认关闭主动避障。导航预览前，停止交接已完成；新 Nav2Obstacles 将 local/global obstacle_layer.enabled 写为开关值，并清理旧代价地图。所有参数服务成功后才记录实际状态；任一步失败不生成可启动预览。关闭时静态地图层继续参与全局及局部规划，动态雷达近障由最终防撞停车；开启时雷达 marking/clearing 参与 Nav2 局部与全局规划，DWB 负责绕行。保留雷达健康检查和真实车体尺寸。静态地图中已存在的障碍不会因开关关闭而消失。

开关变更后下一次预览生效，界面区分已保存选择与 Nav2 已确认状态。删除界面的防护模式选择，仅保留原主动避障开关及现有数值设置、状态区域。兼容旧 API 的 protection_mode 字段，导航统一使用新的局部防撞路径，不增加用户模式。

普通 blocked/braking/waiting_observation 输出零速度但保持导航租约，持续接收新鲜指令并重新检查，净空恢复后继续；连续阻挡 20 秒终止任务（与现有 Nav2 20 秒进度检查量级一致，实车须校核）。传感器故障、无效指令、指令过期、租约过期、急停和明确停止仍立即停车或撤权。未延长任何旧速度证据寿命。

## 修改文件

- local_collision_guard.py、avoidance.py：消除导航重复扩张，预测时长仍覆盖实测转动制动时间。
- decision_controller.py：导航走局部防撞，普通障碍不撤权、持续阻挡终止；原安全门控保留。
- nav2_obstacles.py（新增）、navigation_bridge.py：Nav2 参数握手与代价地图清理、预览设置一致性、实际状态、首个停车原因。
- config/navigation.yaml：local costmap 增加静态层；两套动态障碍层默认关闭，预览时按开关确认。
- AvoidanceSettingsPanel.tsx、DrivePad.tsx、labNavigation.ts：保留布局和原开关，显示实际 Nav2 状态及必要说明。
- test_navigation_obstacles.py（新增）、test_navigation_bridge.py：真实控制器方法与几何仿真、参数协议、设置变更与旧预览拒绝。

## 后续部署与实测记录（2026-11-17）

用户授权后，车端部署为 insightrover-v411-nav-obstacles-7ffdba37e2d6，电脑客户端同步更新，版本仍为 4.1.1。上传包含 navigation.yaml；部署后校验代码与界面哈希，启动保持 stop。Nav2 新服务客户端增加最多 2 秒发现等待，不延长雷达或速度证据有效期。

第一次低速短距实测：里程计最大位移约 0.241 米，现场确认确实前进并停住。近障制动期间保留租约并恢复输出；随后采样角速度 0.18 rad/s 超过该次测试 0.15 rad/s 上限，监测发出停车。客户端另返回目标确认超时，且旧 Nav2 任务残留，随后显式取消并确认 Goal canceled。不得视为到点成功。开启主动避障后参数握手与路线预览通过，未做实车绕障。

经再次授权的第二次实测：预览、租约及目标确认成功，里程计最大位移约 0.142 米；之后主要输出约正负 0.0395 rad/s 小幅转向，无新防撞拦截或监测超速。Nav2 两次报告 Failed to make progress；45 秒未完成到点，清理取消目标。实际 xy_goal_tolerance=0.15、yaw_goal_tolerance=0.2、progress_checker.movement_time_allowance=20；剩余路径反馈约 0.153 米，不能把剩余路径长度等同于精确欧氏目标误差。底盘低速转动响应、末段控制及定位波动需进一步验证，未据此放宽容差。
