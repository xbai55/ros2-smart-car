# 新建地图直接用于任务（4.0.5）

后续变更：4.0.6 已按用户要求移除实车验收记录对执行的限制，见 `vehicle-size-4.0.6.md`；下述测试结果仍是 4.0.5 当时的记录。

建图页面新增“结束建图并用于任务”。点击后填写地图名称，系统停车，捕获本轮地图与地图坐标中的当前位置，保存地图，结束 SLAM，加载 Nav2/AMCL，并自动发送一次初始位姿。定位检查通过后自动进入任务页面，沿用 SLAM 原始坐标，不需要人工四点标定。普通“保存地图”和“退出建图模式”保留原来的用途。

自动复用只适用于同一车端进程中刚结束的建图：位姿有效期为 60 秒，地图资产必须完全匹配，里程计必须新鲜且连续。交接期间移动超过 5 厘米、转动超过 3 度、里程计时间倒退、切换地图或重启进程都会阻止自动复用。定位仍须通过原有协方差和至少 3 秒静止稳定性检查。

准备期间驾驶按钮暂停，停止和急停仍可用。后台持久化准备进度，支持查询、取消和重复请求去重；应用重启后标记中断，不重放自动定位。失败后保留已经登记的地图，并提供进入该地图手动定位的入口。任务执行仍受原有权限、能力验收和控制租约约束。
