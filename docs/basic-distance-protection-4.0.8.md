# 基础防护 4.0.8 修复与部署

4.0.8 已部署到小车，并覆盖安装电脑客户端。当前设置为基础防护、主动绕行关闭；原绕行触发距离 0.4 米保留。完整防护可在设置中开启。未发送任何行驶指令，未开展实车行驶验收。

## 原因和修改

4.0.7 将正常雷达缺测一律视为空间未确认。现有扫描回放包含 112 条未知、29 条未采样射线，严格空间覆盖检查会拦住前后、横移及转动六个方向。这能解释所采样场景下的无法放行，不能据此推断所有历史停车事件都来自同一原因。

基础模式改用实际障碍回波检查车体平移和转动扫掠空间，保持车体尺寸、自体过滤范围、间隙和制动模型；不把未知射线伪造成已观测空地。完整模式保留观测覆盖检查。正常缺测不再单独触发基础停车，雷达整体无有效测距、数据过期或安装变换不可用仍会停车。距离模式降低了未知空间保护能力，遮挡区域仍可能存在未检测障碍，须有人看护。

基础局部防撞不依赖全局位姿；仍需及时、可信的底盘速度证据来计算运动包络。主动绕行执行时仍检查其必要的位姿条件。导航、搜索等任务前提继续限于对应任务，不锁住无关手动驾驶。

同一用户、客户端、车辆、用途的健康手动控制权可以复用，减少重复停车申请。其他客户端接管仍经过停车确认。松手、断连、指令过期、急停、速度限制、无效指令拒绝及控制权互斥继续保留，未延长原超时。

首次拦截的原驾驶意图现在会保留在诊断事件中，避免故障作废意图后漏记拦截。

涉及主要文件：车端 avoidance.py、footprint.py、local_collision_guard.py、decision_controller.py、control_lease.py；后端 operator_control.py、control_leases.py、vehicle_control.py、robots.py；前端 robotApi.ts、AvoidanceSettingsPanel.tsx。未混入地图或视觉识别重构。

## 验证范围

车端离线 529 项通过，另有 5 个子测试通过；两项已在改动前复现的原有失败单列排除。后端 219 项、前端 128 项通过。新增真实扫描回放覆盖六方向放行、真实近障停车、安全后退、整体扫描失效、主动绕行开关与位姿解耦、首次拦截诊断；后端和前端覆盖同客户端复用及序号衔接。

实际安装程序已确认版本及内置界面哈希、真实状态读取、状态推送、设置匹配回执，以及静止状态下控制权申请、同客户端复用和释放。最终控制权无人持有、模式 stop。只读订阅得到 61 条零速度输出，/cmd_vel 唯一发布者为 decision_controller。车端 62 个模块源文件与上传清单一致。

这些检查不证明实际制动距离、盲区安全、近车体回波来源或底盘失联停车能力。右侧约 11～12 厘米回波来源仍待实车核验；没有扩大过滤范围或缩小车体来规避。
